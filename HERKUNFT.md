# Herkunft

Dieses Repository baut auf meinem Einzelprojekt SolarPipeline auf,
Case Study im Studiengang Big Data und Data Science.

Der erste Commit übernimmt den Stand aus dem Einzelprojekt unverändert,
Commit 5b135d7 vom 14.09.2026 aus github.com/devsdaub/wbh_solarpipeline.
Dazu gehören Pipeline, Datenbank, Dashboard und Tests. Die Historie
dieser Grundlage bleibt im dortigen Repository nachvollziehbar.

Alles ab dem zweiten Commit gehört zur Bachelorarbeit „Ertragsprognose
für Balkonkraftwerke mit maschinellem Lernen: Methodenvergleich und
Analyse des Einflusses externer Datenquellen". Das Analyse-Modul liegt
unter app/analytics.
